## Agent skills

### Issue tracker

Issues and PRDs are tracked as local Markdown under `.scratch/`; pull requests are not a request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The repository uses the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` status vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

The repository uses a single-context domain layout. See `docs/agents/domain.md`.
